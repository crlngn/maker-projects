# maker-projects

A collection of personal explorations and prototypes — small projects built
mostly to learn, try out tools, and see how far simple ideas can be taken.

## Projects

- **[local-vision/](./local-vision/)** — a local-first vision observation
  prototype. Watches a video stream, samples frames, asks a local
  vision-language model a yes/no question about each one, and fires
  triggers when conditions are sustained (or absent). Built around Gemma 4
  E2B-it via Ollama. Demo tracks water consumption while working.
