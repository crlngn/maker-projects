How it is built

A small Python service that watches a video stream and asks a local vision-language model a yes/no question about each sampled frame. No cloud APIs — everything runs on the machine.

Model. Gemma 4 (E2B-it) served by a local Ollama instance. For each sample we send one JPEG frame plus a templated prompt asking for yes/no followed by a one-sentence reason.

Sampling. Frames are pulled from the source at a fixed rate (≈1 Hz). Anything between sample points is skipped — inference only runs on the chosen frames, so the model's cost is bounded regardless of source FPS.

State machine. A trigger evaluator turns the stream of yes/no answers into events. It tracks the current "true-episode" — an unbroken run of yes-frames. In sustained mode it fires once the episode has lasted ≥ N seconds; in instant mode it fires on the first yes. Either way it re-arms only when the answer flips back to no, so one continuous episode produces at most one event.
